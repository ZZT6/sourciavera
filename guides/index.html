How to read a guide

Every supplier profile uses the same fields

So you can compare suppliers side by side — and see exactly which facts we confirmed in person and which we didn't.

CompanyLegal name as registered, not the Alibaba store name — plus website when we have it.
LocationProduction address. If it differs from the registered address, we say so.
ProductsWhat they make in-house vs. what they buy in and resell.
Export marketsWhere they already ship — and which standards they know.
Suitable buyer typeSmall importer, regional distributor, Amazon seller, large wholesaler, OEM buyer.
MOQRealistic minimum order, not the listing headline.
