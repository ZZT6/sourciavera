# Tabler Icons used in the data briefs

- Source: Tabler Icons, https://github.com/tabler/tabler-icons (npm `@tabler/icons` v3.35.0, `icons/outline/`)
- Licence: MIT, (c) 2020-2025 Pawel Kuna. Full text in `LICENSE` in this folder.
- Files here: database, arrows-left-right, settings, calendar, calculator, download. They are the unmodified source SVGs.
- Use: the SVG paths are inlined in the pages (class `spec-ic`, `stroke="currentColor"`, 20px) by the `spec_table()` component of the data-brief generator; nothing is loaded from a CDN.
- Row to icon map ("Method and sources" table): Source = database, Flow and partners = arrows-left-right, Product = settings, Periods = calendar, Calculation = calculator, File = download.
- No logo or emblem of the United Nations, UN Comtrade or any other institution is used on the site: sources are named in text and linked.
